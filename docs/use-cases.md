# Use Cases

## Actors
- End user
- API consumer
- Maintainer
- Administrator

## Primary Use Cases

### UC01 - Perform a basic arithmetic operation
The user enters two values and selects an arithmetic operation. The system calculates the result and displays it on the selected client interface.

### UC02 - Perform an advanced operation
The user selects operations such as square root, square, or reciprocal and receives the corresponding result.

### UC03 - Create and evaluate a full formula
The user enters an expression containing at least two numbers and one operator, such as 1 + 2 - 6 / 4 * 8 + 10%, and the system evaluates it using the correct mathematical precedence rules.

### UC04 - Validate input
The system rejects invalid input such as empty values, unsupported operators, or malformed expressions.

### UC05 - Access the calculator from different platforms
The same calculation flow must be available in the web, mobile, and desktop clients.

### UC06 - Secure API access
A registered user or service can authenticate and access protected calculator operations through the API.

### UC07 - Monitor and troubleshoot
Maintainers can inspect logs and errors to diagnose issues and improve reliability.
